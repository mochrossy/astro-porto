## Kenapa Astro?

Astro is a static site generator that is perfect for blogs and
portofolio karena:

— generates static HTML without excessive JavaScript

- **SEO-friendly** — search engines love static sites
- **Flexible** — supports components from React, Vue, or Svelte
- **Markdown-first** — focuses on content, not code
