For most of my career as an IT engineer, I was not a full-time coder.

I started in 2006. I worked with Linux, Windows, PHP, SQL, Bash, mail servers, DNS, proxies, and databases. I migrated systems, maintained infrastructure, managed projects, and led IT service operations. Coding was always part of my work, but over time, it became something I used to do — not something I did every day.

Then I decided to start again.

This blog is part of that journey. And Astro is the reason it finally happened.

## What Is Astro?

Astro is a modern web framework for building content-focused websites: blogs, portfolios, documentation, and personal sites. It lets you write components, use Markdown, and generate fast static HTML. By default, Astro ships zero JavaScript, so your site stays lightweight and quick. If you need interactivity, you can add React, Vue, Svelte, or plain JavaScript when you actually need it.

In short: Astro is designed for people who want to build websites without fighting a complicated setup.

## Why Astro Felt So Easy

I had tried to get back into coding before. But the modern web ecosystem felt overwhelming. There were so many tools, frameworks, and configuration files. I spent more time setting things up than actually building.

Astro was different.

- **File-based routing.** Create a file, get a page. That’s it.
- **Markdown support.** I can write posts like this one without touching a database.
- **Familiar syntax.** If you know HTML, you already know a lot of Astro.
- **Bring your own CSS.** Use plain CSS, Tailwind, or whatever you like.
- **No complex state management.** You don’t need to learn a huge framework just to publish a blog.
- **Great for portfolios.** It is built for exactly this kind of site.
- **Start small.** You can begin with one page and grow from there.

Within hours, I had a working blog. It was not perfect. But it was mine. And that small win mattered more than I expected.

## Starting Coding Again

I spent years as a system engineer, DBA, project manager, and DevOps engineer. I worked with banks, mining companies, telcos, and automotive clients. I managed infrastructure, incidents, disaster recovery, and teams. I wrote scripts when needed, but I missed building things from scratch.

Coming back to coding was not easy. I had to accept that I had forgotten things. I had to be patient with myself. I had to start small.

Astro helped because it did not force me to learn everything at once. I could use my existing knowledge of HTML, CSS, and Markdown. I could focus on writing and building, not on configuring build tools.

This blog is the result. It is a place for me to document my journey, share what I learn, and rebuild my coding skills one post at a time.

## What I’m Learning Now

- Building my portfolio with Astro.
- Writing about my IT journey.
- Revisiting PHP, SQL, and Bash with a fresh perspective.
- Exploring how infrastructure and development connect.
- Documenting as I go, so I can look back and see progress.

## If You’re Also Coming Back to Code

You do not need to catch up on everything. You do not need to master the entire modern stack before you start. Pick a tool that meets you where you are. For me, that tool was Astro.

Start with one page. One post. One component. Then keep going.

This blog is proof that you can start again. It is not perfect. But it is a start. And that is enough.
