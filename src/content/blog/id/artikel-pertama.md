## Kenapa Astro?

Astro adalah static site generator yang sangat cocok untuk blog dan
portofolio karena:

- **Cepat** — menghasilkan HTML statis tanpa JavaScript berlebih
- **SEO-friendly** — mesin pencari menyukai situs statis
- **Fleksibel** — bisa pakai komponen dari React, Vue, atau Svelte
- **Markdown-first** — fokus ke konten, bukan kode
