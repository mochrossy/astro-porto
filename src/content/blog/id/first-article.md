Setelah bertahun-tahun di infrastruktur dan operasional IT, saya mulai ngoding lagi. Ini alasan Astro membuatnya mudah, menyenangkan, dan layak.
Selama sebagian besar karier saya sebagai IT engineer, saya bukan seorang programmer full-time.

Saya mulai tahun 2006. Saya bekerja dengan Linux, Windows, PHP, SQL, Bash, mail server, DNS, proxy, dan database. Saya migrasi sistem, memelihara infrastruktur, memimpin proyek, dan mengelola operasional layanan IT. Coding selalu menjadi bagian dari pekerjaan saya, tapi seiring waktu, coding jadi sesuatu yang "dulu saya kerjakan" — bukan sesuatu yang saya lakukan setiap hari.

Lalu saya memutuskan untuk mulai lagi.

Blog ini adalah bagian dari perjalanan itu. Dan Astro adalah alasan kenapa akhirnya hal itu terwujud.

## Apa Itu Astro?

Astro adalah framework web modern untuk membangun situs yang berfokus pada konten: blog, portofolio, dokumentasi, dan situs personal. Astro memungkinkan kita menulis komponen, menggunakan Markdown, dan menghasilkan HTML statis yang cepat. Secara default, Astro tidak mengirim JavaScript sama sekali, jadi situs kita tetap ringan dan cepat. Kalau butuh interaktivitas, kita bisa menambahkan React, Vue, Svelte, atau JavaScript biasa saat memang diperlukan.

Singkatnya: Astro dirancang untuk orang yang ingin membangun website tanpa harus berkelahi dengan setup yang rumit.

## Kenapa Astro Terasa Begitu Mudah

Sebelumnya saya sudah pernah mencoba kembali ke dunia coding. Tapi ekosistem web modern terasa membingungkan. Terlalu banyak tools, framework, dan file konfigurasi. Saya lebih banyak menghabiskan waktu untuk setting daripada benar-benar membangun sesuatu.

Astro berbeda.

- **Routing berbasis file.** Buat satu file, dapat satu halaman. Selesai.
- **Dukungan Markdown.** Saya bisa menulis post seperti ini tanpa menyentuh database.
- **Sintaks yang familiar.** Kalau kamu paham HTML, kamu sudah paham sebagian besar Astro.
- **Bebas pakai CSS apa saja.** Mau plain CSS, Tailwind, atau apa pun, terserah.
- **Tanpa state management yang rumit.** Kamu tidak perlu belajar framework besar hanya untuk menerbitkan blog.
- **Cocok untuk portofolio.** Astro memang dibangun untuk situs seperti ini.
- **Mulai dari kecil.** Kamu bisa mulai dari satu halaman, lalu berkembang dari situ.

Dalam hitungan jam, saya sudah punya blog yang berjalan. Belum sempurna. Tapi itu milik saya. Dan kemenangan kecil itu ternyata jauh lebih berarti dari yang saya duga.

## Mulai Ngoding Lagi

Saya menghabiskan bertahun-tahun sebagai system engineer, DBA, project manager, dan DevOps engineer. Saya bekerja dengan klien dari perbankan, pertambangan, telekomunikasi, dan otomotif. Saya mengelola infrastruktur, insiden, disaster recovery, dan tim. Saya menulis script saat dibutuhkan, tapi saya merindukan momen membangun sesuatu dari nol.

Kembali ke coding tidak mudah. Saya harus menerima bahwa banyak hal yang sudah saya lupakan. Saya harus sabar dengan diri sendiri. Saya harus mulai dari kecil.

Astro membantu karena tidak memaksa saya mempelajari semuanya sekaligus. Saya bisa memanfaatkan pengetahuan yang sudah saya punya tentang HTML, CSS, dan Markdown. Saya bisa fokus menulis dan membangun, bukan mengurus konfigurasi build tools.

Blog ini adalah hasilnya. Ini tempat saya mendokumentasikan perjalanan, membagikan apa yang saya pelajari, dan membangun kembali kemampuan coding saya satu post demi satu post.

## Apa yang Sedang Saya Pelajari Sekarang

- Membangun portofolio dengan Astro.
- Menulis tentang perjalanan karier IT saya.
- Meninjau ulang PHP, SQL, dan Bash dengan perspektif baru.
- Menjelajahi bagaimana infrastruktur dan development saling terhubung.
- Mendokumentasikan semuanya sambil berjalan, supaya saya bisa melihat kembali kemajuan saya.

## Kalau Kamu Juga Sedang Kembali ke Coding

Kamu tidak perlu mengejar semua hal. Kamu tidak perlu menguasai seluruh stack modern sebelum memulai. Pilih satu tool yang bisa menyesuaikan dengan posisimu saat ini. Bagi saya, tool itu adalah Astro.

Mulai dari satu halaman. Satu post. Satu komponen. Lalu lanjutkan.

Blog ini adalah bukti bahwa kamu bisa memulai lagi. Belum sempurna. Tapi ini sebuah awal. Dan itu sudah cukup.

Kalau kamu juga seorang profesional IT yang sedang kembali ke dunia coding, saya akan senang mendengar ceritamu. Jangan ragu untuk menghubungi saya.
