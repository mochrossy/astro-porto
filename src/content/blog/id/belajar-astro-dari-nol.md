Astro adalah framework modern untuk membangun situs web berbasis konten.
Berbeda dengan Next.js atau Nuxt yang mengirim JavaScript berat ke browser,
Astro mengirim **nol JavaScript** secara default.

## Instalasi

```bash
npm create astro@latest proyek-baru
cd proyek-baru
npm install
npm run dev
```
