## Background

The portfolio website required an easy-to-use admin system to manage
content (posts, portfolio, skills, clients).

## Solution

Used **Filament v5** — a modern admin panel for Laravel that provides
automatic CRUD, form builder, and table builder.

## Admin Panel Features

- **Posts** — CRUD for blog articles with image upload
- **Projects** — CRUD for portfolio projects
- **Portfolios** — work gallery with complete details
- **Skills** — list of skills with proficiency level
- **Clients** — client logos and information
- **Search & filter** on all tables
- **Bulk actions** for mass operations

## Lessons Learned

Building the CRUD manually first before Filament greatly helped in
understanding the fundamentals of Laravel (Route → Controller → Model → View).
