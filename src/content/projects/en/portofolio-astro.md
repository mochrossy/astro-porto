## Goal

Build a fast, lightweight, and affordable personal portfolio website.
After previously using Laravel, this time choosing a Static Site
Generation approach with Astro.

## Why Astro?

- **Zero JavaScript by default** — pure HTML output
- **Markdown-first** — focus on content
- **Fast build** — build process takes only seconds
- **Free deploy** — Cloudflare Pages at no cost

## Features

- Blog with Content Collections
- Portfolio with complete details
- Search engine friendly (SEO)
- Sitemap XML and RSS feed

## Results

Website live with a Lighthouse score of 100 in all categories.
Hosting cost: **$0** (Cloudflare Pages free tier).
