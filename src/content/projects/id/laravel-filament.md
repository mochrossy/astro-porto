## Latar Belakang

Website portofolio membutuhkan sistem admin yang mudah digunakan
untuk mengelola konten (post, portfolio, skill, client).

## Solusi

Menggunakan **Filament v5** — admin panel modern untuk Laravel yang
menyediakan CRUD otomatis, form builder, dan table builder.

## Fitur Admin Panel

- **Posts** — CRUD artikel blog dengan upload gambar
- **Projects** — CRUD proyek portfolio
- **Portfolios** — galeri karya dengan detail lengkap
- **Skills** — daftar keahlian dengan level
- **Clients** — logo dan informasi klien
- **Search & filter** di semua tabel
- **Bulk actions** untuk operasi massal

## Pembelajaran

CRUD manual dulu sebelum Filament sangat membantu memahami
konsep dasar Laravel (Route → Controller → Model → View).
